# My Sticky Notes (轻量级随手便签 & 进度跟踪)

极轻量、低内存占用、无任务栏图标常驻、常驻 Windows 右下角系统托盘的便签与日常待办进度跟踪原生桌面小工具。

---

## 🌟 核心特性

1. **极轻量、极低资源开销**：
   - 纯 Win32 API + C++20 + GDI 原生打造，单可执行文件体积仅 **约 200 KB**。
   - 彻底告别 Electron (150MB+) 与 Webview (50MB+)，私有内存占用仅约 **5 MB**，待机 CPU **0%**。
2. **纯粹托盘常驻，无任务栏图标打扰**：
   - 采用 Windows 底层隐藏 Owner + `WS_EX_TOOLWINDOW` 机制，**绝不占用底部任务栏位置**。
   - 右下角系统托盘显示便签专属黄色小图标。
3. **日常待办与进度跟踪 (Progress Tracking)**：
   - **实时进度条**：显示已完成/总项数及百分比进度，绿条可视化进度。
   - **交互便捷**：输入框回车或点击「添加」快速录入；单击待办项或复选框即刻打钩并划线；悬浮显示删除按钮「×」。
   - **自由速记 (Scratchpad)**：一键 Tab 切换到多行便笺，随时记录临时命令、想法与笔记。
4. **置顶与快捷操作**：
   - 顶部 Header 点击 `[置顶]` 快速切换窗口始终置顶。
   - 点击 `一` 或托盘单击快速隐藏到后台，随时唤醒。
   - 窗口边缘 8 个方向支持自由拉伸调整大小，位置与尺寸自动记忆。
5. **本地自动持久化**：
   - 输入与操作后防抖自动落盘至 `%APPDATA%\MyStickyNotes\notes_data.json`，重启后所有待办与文本完整恢复。

## 🚀 编译与构建

项目采用标准 GCC/MinGW-w64 工具链（支持 MSYS2 / MinGW64）：

```bash
# 执行自动化编译命令
g++ -std=c++20 -O2 -mwindows -municode src/data_store.cpp src/tray.cpp src/main.cpp -o my-sticky-notes.exe -lcomctl32 -lgdi32 -luser32 -lshell32 -ladvapi32 -lshlwapi
```

也可以直接双击或在终端执行：
```powershell
.\build.bat
```

## 💻 使用说明

1. 运行 `my-sticky-notes.exe` 后，屏幕左上角弹出便签窗口，右下角系统托盘生成专属便签图标。
2. **托盘操作**：
   - **左键单击托盘图标**：显示 / 隐藏便签窗口。
   - **右键单击托盘图标**：弹出快捷菜单（快速新建待办、显示/隐藏便签、切换置顶、退出程序）。
3. **便签操作**：
   - 拖拽顶部栏可随意移动便签。
   - 拖动窗口边缘可自由调整长宽。
   - 单击顶部 `[置顶]` 按钮可锁定在最顶层（方便边对照边敲代码）。
